# 物料搬运机器人设计思路与技术实现（W4A）

## 1. 任务目标与约束

本项目基于 ROS 构建物料搬运机器人，目标是在限时条件下完成两轮“抓取-放置-返航”任务。核心约束如下：

- 任务流程完整：起点出发、货架识别、抓取、分拣放置、重复两次、返回起点。
- 赛场存在障碍物：需要依赖导航规划与局部避障稳定通过。
- 时间敏感：在保证成功率前提下尽量缩短总任务时长。

## 2. 总体系统架构

系统采用“导航层 + 视觉识别层 + 机械臂执行层 + 主流程调度层”的分层结构：

- 主流程调度：`complete_flow_mm_m.cpp`，负责任务编排与状态切换。
- Tag 识别与车身微调：`print_id.cpp`，解析 AprilTag 位姿并触发抓取流程。
- 机械臂抓取：`arm_grab.cpp`，基于 TF 坐标变换与偏置补偿执行抓取。
- 机械臂放置：`arm_put.cpp`，执行目标位卸货与机械臂回零。

## 3. 全流程技术实现

### 3.1 安全快速起步（非直接导航）

为兼顾起步速度与安全性，主程序采用“左平移 + 前进 + 导航”的分段起步策略，而非直接给 `move_base` 目标点：

- 左平移：先脱离起点附近可能的局部拥挤区域。
- 前进：快速建立更稳定的初始姿态。
- 再导航：降低起始阶段路径抖动和碰撞风险。

实现位置：`complete_flow_mm_m.cpp` 中 `move_safe(pub, 0.0, 0.2, 18)` 与 `move_safe(pub, 0.3, 0.0, 60)`。

### 3.2 导航与避障

系统使用 `move_base` 进行全局+局部规划。主程序通过 `sendGoal()` 发送导航目标，若状态为 `ABORTED`，触发重试机制：

- 先小幅后退，解除局部卡死或障碍贴近状态。
- 再次发送同一目标点，提升到达成功率。

实现位置：`complete_flow_mm_m.cpp` 中 `sendGoal()` 与 `performRetryLogic()`。

### 3.3 货架识别与车身微调

到达货架后，启动 `print_id.launch`，进入 AprilTag 识别与姿态判断：

- 读取 Tag 位姿和四元数。
- 将四元数转换为欧拉角（roll/pitch/yaw），用于判断是否为“侧面视角”。
- 若姿态偏差过大，先横向平移再后退，重新建立更适合抓取的视角。
- 检测到有效 Tag 后，发布 `/detected_tag_id`，并按 ID 触发 `arm_grab_1.launch` 或 `arm_grab_2.launch`。

该策略本质上将“识别”与“微调”绑定为闭环，提升了视觉定位稳定性。

实现位置：`print_id.cpp`。

### 3.4 机械臂抓取微调（车体+机械臂双层补偿）

抓取节点 `arm_grab.cpp` 采用两级补偿：

- 车体补偿：根据 `arm_base_link -> tag_x` 的 TF 平移量，先对底盘做小范围前后/左右修正，避免机械臂工作空间边缘抓取。
- 机械臂补偿：将 Tag 坐标转换为毫米坐标后叠加经验偏置 `bias_x/bias_y/bias_z`，补偿吸盘、安装误差和视觉噪声。

随后调用：

- `/control_center/arm_pos_service` 到达预抓取位与下探位；
- `/control_center/grab_service` 执行吸取；
- 抬升并回到安全位。

该设计能同时减少“底盘偏差”和“末端偏差”带来的抓取失败。

### 3.5 分拣放置与二次循环

主流程订阅 `/detected_tag_id` 后，根据识别 ID 执行分拣放置：

- ID=1 导航到放置区 1；
- ID=2 导航到放置区 2；
- 到位后调用 `arm_put.launch` 卸货；
- 卸货后统一后退，避免机械臂/货架干涉。

完成第一次后重置 `tag_received/tag_id`，再执行第二轮抓取放置，最后返航到起点附近并进行车身收尾微调。

实现位置：`complete_flow_mm_m.cpp` + `arm_put.cpp`。

## 4. 设计思路优化（针对调试经验）

### 4.1 起步策略优化表达

原始思路：先左平移、前进，再导航。  
优化表述：采用“安全起步走廊”策略，先通过短程开环位移将机器人移入低风险区域，再切换到 `move_base` 闭环导航，实现起步阶段“快且稳”。

### 4.2 视觉微调优化表达

原始思路：用摄像头做前后左右微调，涉及欧拉角与四元数。  
优化表述：构建“位姿可信度筛选 + 视角修正”机制，通过四元数到欧拉角转换识别侧视异常姿态，并触发横移/后退重定位，提升 Tag 识别稳定性和抓取对准精度。

### 4.3 抓取补偿优化表达

原始思路：机械臂抓取前做左右微调。  
优化表述：引入“底盘粗补偿 + 机械臂精补偿”的双层误差收敛模型，先缩小目标相对位置误差，再由机械臂偏置补偿完成末端精定位，提高抓取成功率。

### 4.4 放置区策略优化表达

原始思路：精心设计放置区导航角度和卸货动作。  
优化表述：采用“目标点位+朝向协同优化”的放置策略，将底盘入位角与机械臂卸货轨迹联合设计，减少二次调整时间并降低放置碰撞风险。

## 5. 时间优化与工程经验

项目中已体现的提速思路：

- 用短程速度控制替代部分慢速重规划过程，减少等待时间。
- 将识别、抓取与放置做成两轮可重复模板，降低流程切换开销。
- 导航失败时快速重试而不是长时间原地等待。

建议的进一步优化方向：

- 将阈值与坐标硬编码改为 ROS 参数，便于赛前快速整定。
- 将 `system("roslaunch ...")` 替换为统一状态机调度，减少节点重复拉起的时间损耗。
- 为关键阶段增加超时与失败分支（识别超时、抓取失败重试、放置失败回退），提升极端场景稳定性。

## 6. 结论

本方案核心优势是：在“导航闭环”的基础上，叠加“视觉微调闭环”和“抓取补偿闭环”，形成多层误差收敛链路。在限时与障碍环境下，该架构兼顾了速度、稳定性和任务完成率，适用于竞赛场景的高强度连续作业。
